Tạo file .book

Chuyển TXT / Aozora Bunko / EPUB sang định dạng của máy đọc sách tiếng Nhật. Mọi xử lý diễn ra ngay trong trình duyệt — tệp không rời khỏi máy bạn.

Kéo thả tệp vào đây, hoặc bấm để chọn
Hỗ trợ nhiều tệp .txt / .epub cùng lúc
Cách đưa lên máy & đăng trang web này lên GitHub Pages

Đưa sách vào máy:

  1. Tải file .book ở trên về điện thoại/máy tính.
  2. Trên máy đọc: mở menu (giữ nút trên cùng) → chọn WiFi転送.
  3. Vào WiFi tên Reader-XXXX (mật khẩu hiện trên màn hình).
  4. Mở trình duyệt, vào http://192.168.4.1, kéo thả file .book để tải lên.
  5. Giữ nút「戻る」trên máy để tắt WiFi. Sách xuất hiện trong 本棚 (thư viện).

Đăng trang này lên GitHub Pages:

  1. Tạo repo mới trên github.com.
  2. Add file → Upload files, kéo cả thư mục web/ (index.html, converter.js, entities.js, glyphs.js) vào, Commit.
  3. Settings → Pages → Source: Deploy from a branch, chọn nhánh main / thư mục / (root), Save.
  4. Đợi ~1 phút rồi mở đường link GitHub cấp.

Trang tĩnh, không gửi dữ liệu, không theo dõi. Cần trình duyệt hiện đại (Chrome/Edge/Safari/Firefox mới).
